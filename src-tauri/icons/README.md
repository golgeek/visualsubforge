# Development icon

`source.svg` is an original geometric waveform drawn for this scaffold; it contains no legacy or third-party assets and is not final product branding.

Regenerate with `npm run tauri -- icon src-tauri/icons/source.svg`. Retain `icon.png`, `icon.ico`, and `icon.icns`; the command also emits mobile/store variants which this desktop-only scaffold does not use.
