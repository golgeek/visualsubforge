# Working with projects

A `.vsfproject` stores references to your media and working subtitle file, along
with workspace settings. Choose **File → Save Project** to create one. Keep the
project and its files together when moving a folder between machines. References
inside the project folder use relative paths with forward slashes.

When you open different subtitles, recover or extract a copy, start a review or
choose a revised file for comparison, the dialog shows the project's saved
subtitle reference. **Use in project** keeps the project attached. **Open without
project** detaches it before opening the subtitles. **Cancel** keeps your current
workspace. Closing subtitles offers **Close without project** in place of Open.

If the same action opens a different video, including a subtitle/video pair from
a drop or Recent, choose **Open without project** to open both files or **Cancel**
to keep working. If the video is the project's own media you can also choose
**Use in project**. When closing the only subtitle in a subtitle-only project,
**Close without project** leaves the saved project available to reopen.

Saving the subtitles under another name changes the working file. On the next
project save, including Save Project As or saving the layout, **Update project**
writes the displayed subtitle reference. **Cancel** leaves the project file as
saved. During quit, **Quit without updating the project** exits with the previous
reference. Choosing **Discard changes** at the unsaved-work prompt also leaves
the saved relationship intact.
