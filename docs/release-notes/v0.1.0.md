# VisualSubForge 0.1.0 (test release)

VisualSubForge is an early desktop subtitle editor. You can time cues against a waveform, preview subtitles on video and save UTF-8 SRT, ASS/SSA and WebVTT files. Please try it with the synthetic test media or a copy of your work.

| Computer | Download | Install |
| --- | --- | --- |
| Apple Silicon, macOS 15 or newer | `VisualSubForge_0.1.0_aarch64_macos.zip` | Unzip and drag VisualSubForge to Applications. |
| Intel Mac, macOS 15 or newer | `VisualSubForge_0.1.0_x86_64_macos.zip` | Unzip and drag VisualSubForge to Applications. |
| Windows x64 | `VisualSubForge_0.1.0_x64-setup.exe` or `VisualSubForge_0.1.0_x64_windows.zip` | Run the installer, or extract the entire portable ZIP. Windows may need to install the WebView2 runtime. |
| Ubuntu 22.04, 24.04 or 26.04 and Debian 12 or 13 (amd64 or arm64) | `VisualSubForge_0.1.0_amd64.deb` or `VisualSubForge_0.1.0_arm64.deb` | Run `sudo apt install ./filename.deb` with the downloaded filename. |
| Fedora 45 (amd64 or arm64), Arch Linux (amd64) and per-user installs on Ubuntu or Debian | `VisualSubForge_0.1.0_x86_64_linux.tar.gz` or `VisualSubForge_0.1.0_aarch64_linux.tar.gz` | Extract, enter the directory and run `./install.sh`. |

The Mac apps are Developer ID signed and notarized. This first Windows build is unsigned. SmartScreen may show “Windows protected your PC”. After checking the download against `SHA256SUMS`, choose **More info → Run anyway** to proceed. Signed Windows builds are planned for a later version. Physical Windows and Linux graphics, sound and clean installations still need tester reports.

On Linux, the tarball installs under `~/.local/opt/visualsubforge`. If the
launcher reports missing libraries, Fedora users can run
`sudo dnf install webkit2gtk4.1 gtk3 libva` and Arch users can run
`sudo pacman -S webkit2gtk-4.1 gtk3 libva`. On Ubuntu and Debian, the
launcher prints the apt command for the installed distribution version.
To remove a per-user installation, run `~/.local/opt/visualsubforge/uninstall.sh`.
For a Debian package, run `sudo apt remove visualsubforge`.

The optional update check asks on first launch. It contacts GitHub to look for newer versions and offers a link to their release page. You can turn off automatic checks in Settings and use **Help → Check for Updates** at any time.

Download `VisualSubForge-0.1.0-test-media.zip` and follow the [tester guide](https://github.com/golgeek/visualsubforge/blob/v0.1.0/docs/testing-v0.1.md). Send observations using the [test report form](https://github.com/golgeek/visualsubforge/issues/new?template=test-report.yml). Please omit private video, subtitles and identifying paths.
